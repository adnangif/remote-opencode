# opencode-rocks

> **Supports opencode v2 only.** opencode v1 is not supported. If you're still on v1, use `npm i -g opencode-rocks@1` or upgrade opencode with `opencode upgrade`.

Install:

```bash
npm i -g opencode-rocks
```

Use:

```bash
roc configure --guided
roc up
```

`roc` starts an `opencode` server, opens an ngrok or Tailscale tunnel, and prints a QR code for connecting from the mobile app.
