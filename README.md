# Opencode Remote

Opencode Remote is a companion project for controlling an `opencode` session from a phone. It includes a published CLI package and a mobile app:

- `cli/`: TypeScript CLI published as `opencode-rocks`; it installs the `roc` command.
- `app/`: Expo React Native app for scanning a `roc` QR code and opening the remote opencode UI.

## How it works

1. Run `roc up`.
2. `roc` starts `opencode serve` on the pre-configured host and port.
3. `roc` securely exposes the official opencode web interface through ngrok or Tailscale.
4. `roc` prints a tunnel URL and QR code.
5. The mobile app scans the QR code and opens the session in a WebView.

Runtime state is stored in `~/.opencode-proxy.json`.

## CLI

Install:

```bash
npm i -g opencode-rocks
```

Use:

```bash
# Configure once
roc configure --guided

# Start opencode and print a QR code
roc up
```

Run `roc up` from the directory you want opencode to use as its working directory.

While the session is running:

```bash
# Check whether the server and tunnel are running
roc status

# Print the current URL and QR code again
roc share

# Attach the local opencode TUI
roc t

# Stop the server and tunnel
roc down
```

Supported Tunnel providers:

- ngrok: public HTTPS tunnel with generated basic-auth credentials.
- Tailscale: private HTTPS tunnel on your tailnet.

## Mobile app

Download the Android APK from the latest GitHub release:

```text
https://github.com/adnangif/remote-opencode/releases/latest
```

The app scans QR codes generated by `roc up` for both ngrok and Tailscale tunnels. Recently used connections are saved locally on the device.

Android may require allowing installs from unknown sources when installing the release APK.

## Development

Build the CLI:

```bash
cd cli
pnpm install
pnpm build
```

Run the app:

```bash
cd app
npm install
npm run android
```
